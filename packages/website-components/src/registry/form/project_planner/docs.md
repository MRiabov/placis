# public.form.project_planner

## Purpose

Use this component for structured project scoping before a lead is submitted.

## Best Fit

Good for higher-value work where project type, budget, timing, or scope choices
improve lead quality.

## Avoid

Avoid it for urgent or simple services where a quick phone CTA is better.

## Key Props

Use select/range/input fields, summary copy, and submit settings that map to a
CMS form and CRM handoff.

## Style And Composition

The style preset should control input density, grouped controls, summary state,
and CTA hierarchy. Keep the planner understandable on mobile.
