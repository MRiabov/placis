# public.form.callback_bar

## Purpose

Use this component for a compact callback request strip.

## Best Fit

Good between sections when the desired conversion is a quick name/phone
submission rather than a full quote form.

## Avoid

Avoid it for complex requests that need service type, address, uploads, or long
descriptions.

## Key Props

Use `form_id`, title, submit label, and a small field list such as name and
phone.

## Style And Composition

The style preset should control inline/stacked layout, field shape, focus
states, and CTA contrast. It should remain easy to complete on mobile.
