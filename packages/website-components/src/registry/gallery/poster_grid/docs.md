# public.gallery.poster_grid

## Purpose

Use for source pages that present services, sectors, or project categories as
image posters with title overlays. It is intended for image-led contractor,
venue, portfolio, and institutional sites.

## Best Fit

Good for portfolio categories, service-category splash pages, sector grids, and
project-type menus where the image and label carry the navigation.

## Avoid

Keep item data tenant-owned. Do not reuse another company's project categories
or images without explicit evidence and review.

## Key Props

Use `items[]` with `title` or `name`, optional `href`, `image_url`, `caption`,
and `alt_text`.

## Style And Composition

The style preset owns grid density, image ratio, overlay position, title
treatment, hover states, and mobile stacking.
