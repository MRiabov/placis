# public.process.steps

## Purpose

Use this component to explain a contractor's process as ordered steps.

## Best Fit

Good for projects with a clear journey: call, survey, quote, schedule, complete,
and follow-up.

## Avoid

Avoid it for unordered benefit lists or service categories. Use feature or
service components for those.

## Key Props

Use `items[]` with step title and detail copy. Keep each step concise and
operationally true.

## Style And Composition

The style preset should control numbering, spacing, connector treatment, and
responsive stacking. It pairs well with quote CTAs and FAQs.
