# public.contact.cta_panel

## Purpose

Use this component for a strong contact-focused CTA panel with phone, email, and
messaging actions.

## Best Fit

Good near the end of a source-backed page when direct contact should be the
primary next step.

## Avoid

Avoid it when a full lead form is required or when the page already has several
heavy contact sections.

## Key Props

Use heading/copy plus contact methods such as phone, email, address, and
external messaging links.

## Style And Composition

The style preset should control contrast, action button layout, link states, and
responsive stacking. It should be readable before it is decorative.
