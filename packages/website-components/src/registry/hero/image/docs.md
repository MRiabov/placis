# public.hero.image

## Purpose

Use this hero when the contractor has strong visual proof: real project imagery,
credible service imagery, or a generated image that clearly supports the trade
and service area.

The first fixture is decomposed from Bellfield Developments. The reusable
pattern is a full-viewport image-led hero with an uppercase locality eyebrow,
split serif headline, service summary, primary CTA, phone CTA, and bottom proof
strip.

Avoid it when the image is generic, low-trust, or unavailable. Use
`public.hero.type_first` instead when copy and proof should carry the first
viewport.

## Key Props

Use `headline`, `subheadline`, `primary_cta`, `secondary_cta`, `actions`,
`media`, and optional proof text. Keep hero claims backed by a detail when they
mention ratings, guarantees, response time, or years in business.

## Style And Composition

The component should consume the selected CMS style preset for color,
typography, spacing, radius, overlay, and button treatment. Compose it near
navigation, proof bars, or lead forms; do not use it as a mid-page content
block.
