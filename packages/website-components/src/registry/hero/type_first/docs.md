# public.hero.type_first

## Purpose

Use this hero when the first viewport should be carried by copy, proof, and CTAs
rather than a dominant image.

## Best Fit

Good for contractors with weak imagery, B2B offers, specialist services, or
pages where clarity matters more than visual drama.

## Avoid

Avoid it when the site has strong project photography that should establish
trust immediately.

## Key Props

Use `eyebrow`, `headline`, `subheadline`, CTA props, and optional proof points.
Keep the headline literal and service-specific.

## Style And Composition

Typography, color roles, and button hierarchy should be driven by the style
preset. Compose it with proof, services, or a lead form directly below.
