# public.hero.type_first_trust

## Purpose

Use this hero when a typography-led first viewport also needs integrated trust proof and optional background media.

## Best Fit

Good for source-backed rebuilds where the original page combines headline, CTAs, and proof metrics in one opening section.

## Avoid

Avoid it when trust proof is unverified or when the first viewport should remain visually quiet.

## Key Props

Use headline, supporting copy, CTA actions, background media, and proof items. Treat numbers and review claims as source-backed content.

## Style And Composition

The style preset should control contrast, overlay, type scale, CTA hierarchy, and proof strip density. Follow it with service or story content.
