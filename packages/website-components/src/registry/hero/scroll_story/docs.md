# public.hero.scroll_story

## Purpose

Full-viewport brand hero with discrete scroll-story panels. It is meant for
reference sites that use large pinned statements, cinematic imagery, and minimal
calls to action.

The component deliberately models the behavior as named panels, not per-pixel
animation. Public runtime style presets can make those panels sticky,
snap-aligned, or simple stacked sections without changing content. This keeps
the component usable without shipping heavy scroll libraries to every public
website.
