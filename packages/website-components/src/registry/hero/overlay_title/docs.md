# public.hero.overlay_title

## Purpose

Use for first-viewport image intro pages where the source design centers a short page title inside a
translucent overlay band. This variant is reusable for portfolio, institutional construction, venue,
and editorial sites with strong photography.

## Best Fit

Good for multipage sites where each interior page opens with a cinematic image, a short page title,
and minimal or no conversion copy above the fold.

## Avoid

Do not use for lead-generation heroes that need service copy, proof rows, or multiple CTAs above the fold.
Use `public.hero.image` or `public.hero.form` for those cases.

## Key Props

Use `headline` for the centered title and `media` or `image_url` for the background image.
`show_scroll_indicator` controls the small scroll marker.

## Style And Composition

The style preset owns title-band opacity, image height, crop, overlay darkness, typography, and
responsive header interaction.
