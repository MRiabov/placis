# public.hero.form

## Purpose

Use this hero when lead capture must be visible in the first viewport.

## Best Fit

Good for urgent trades, quote-led campaigns, and service pages where the contractor wants visitor details immediately.

## Avoid

Avoid it when the offer requires more explanation before asking for details, or when there is no validated CMS form behind the section.

## Key Props

Use headline and supporting copy with `form_id`, `fields`, submit labels, and trust items. The form schema must validate through CMS form rules.

## Style And Composition

The form should look like part of the selected style preset, not an embedded app panel. Pair it with proof, service area, or FAQ sections that reduce hesitation.
