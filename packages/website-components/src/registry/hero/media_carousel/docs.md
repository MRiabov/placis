# public.hero.media_carousel

## Purpose

First-viewport editorial hero for mature contractors with multiple proof
stories, project categories, or campaign messages. It supports image/video slide
metadata, visible slide tabs, CTA links, 15-second default auto-advance,
reduced-motion opt-out, and a pause/resume control that pauses both the slide
timer and the active video element.

Use when there is enough credible media to justify a full-screen construction
hero. Avoid it for small repair-first sites with one generic photo.

Source fit: PCL-style image/video hero, dark overlay, uppercase labels,
high-contrast accent line, and explicit controls. Source-specific blueprints may
record observed media URLs as provenance, but publication-ready tenant media
should resolve to owned durable assets or tenant media tokens.
