# public.footer.multi_column

## Purpose

Heavy footer for construction groups with several conversion paths, resource columns, social links,
and legal/resource navigation. It is intentionally larger than `public.footer.standard`.

Use for enterprise builders, commercial contractors, and multi-location firms. Avoid it for small
contractors where it would create empty links or unnecessary corporate weight.

Source fit: PCL footer pattern with project/career CTAs, resource navigation, logo, tagline, and
secondary legal/social links.
