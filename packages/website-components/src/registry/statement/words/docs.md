# public.statement.words

## Purpose

Use this component for a short editorial statement with large emphasized words.

## Best Fit

Good for design-led contractor brands, portfolio pages, or transition moments
between major sections.

## Avoid

Avoid it on dense local-service pages where visitors need practical service
details first.

## Key Props

Use statement text and emphasized words sparingly. The copy should be direct and
brand-relevant.

## Style And Composition

The style preset should control type scale, contrast, and spacing. Use it as a
visual break, not as the only explanation of an offer.
