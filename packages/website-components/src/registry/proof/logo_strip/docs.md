# public.proof.logo_strip

## Purpose

Use this component for supplier, product, brand, accreditation, or partner logos
that support trust without needing long explanations.

## Best Fit

Good for source-site logo strips and material/supplier proof rows.

## Avoid

Avoid it when logos imply certifications or partnerships that are not
backed by a detail.

## Key Props

Use `items[]` with `label`, `image_url` or `url`, `alt_text`, and optional
`href`.

## Style And Composition

The style preset should control logo opacity, marquee/static behavior, spacing,
and border rhythm. It should not dominate the conversion path.
