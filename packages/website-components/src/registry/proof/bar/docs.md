# public.proof.bar

## Purpose

Use this component for compact proof rows near a hero, service summary, or CTA.

The first fixture is decomposed from Bellfield's hero stats. Treat numbers, accreditations, ratings, guarantees, and certification claims as source-backed content. If they are imported from a site without verified sources, keep `reviewRequired` true until a contractor or operator approves them.

## Key Props

Use `items[]` for short proof claims. Each item should have a compact label and optional description; avoid long paragraphs or unsupported claims.

## Style And Composition

The component should inherit color, border, density, and typography from the CMS style preset. Place it directly after a hero, before a CTA, or beside a service summary where it can support a conversion claim.
