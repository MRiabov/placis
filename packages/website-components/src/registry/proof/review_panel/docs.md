# public.proof.review_panel

## Purpose

Use this component for a featured review or review cluster that needs more
visual weight than ordinary testimonial cards.

## Best Fit

Good for portfolio or premium contractor pages where one strong review should
anchor a proof section.

## Avoid

Avoid it when all reviews should have equal weight or when review source details
are missing.

## Key Props

Use review quote, author, source, optional controls, and supporting labels.
Treat review claims as source-backed content.

## Style And Composition

The style preset should control panel contrast, source label, quote scale, and
control styling. It pairs well with galleries or contact panels.
