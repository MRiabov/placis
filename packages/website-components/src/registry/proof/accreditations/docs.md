# public.proof.accreditations

## Purpose

Use this component to show insurance, certifications, trade memberships, or source-backed accreditations.

## Best Fit

Good when specific proof marks materially improve trust and the assets or labels are verified.

## Avoid

Avoid it for generic supplier logos or unverified badges. Use `public.proof.logo_strip` for looser logo proof.

## Key Props

Use `items[]` with label, image, alt text, href, and source/review metadata where available.

## Style And Composition

The style preset should control logo sizing, spacing, border treatment, and caption style. Keep the section quiet and credibility-focused.
