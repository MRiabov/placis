# public.marquee.services

## Purpose

Use this component for a compact service/category ticker that shows breadth
without becoming a full services section.

## Best Fit

Good near heroes or between large sections when a contractor has many service
keywords that should remain scannable.

## Avoid

Avoid it when each service needs explanation, imagery, or a dedicated CTA. Use
`public.services.grid`, `public.services.cards`, or `public.services.tabs`.

## Key Props

Use service labels and optional links. Keep labels short enough to scan quickly.

## Style And Composition

The style preset should control motion, spacing, text treatment, and
reduced-motion behavior. It should support the page rhythm, not become the main
proof section.
