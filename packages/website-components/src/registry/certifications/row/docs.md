# public.certifications.row

## Purpose

Use this website component to show insurance, certifications, or trade
memberships backed by a detail.

## Best Fit

Good when specific certification marks improve trust and the assets or labels
are verified.

## Avoid

Avoid it for generic supplier logos or unverified badges. Use
`public.content.logo_strip` for looser logo rows.

## Key Props

Use `items[]` with label, image, alt text, href, and optional
`registry_url`.

## Style And Composition

The website style catalog preset should control logo sizing, spacing, border
treatment, and caption style. Keep the website section quiet and
credibility-focused.
