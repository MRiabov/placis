# public.services.tabs

## Purpose

Use this component for grouped or featured service categories where one service can be explored at a time.

## Best Fit

Good for contractors with several related service families that need image, copy, checklist, and CTA detail.

## Avoid

Avoid it for very small service lists or pages where all services must be visible at once.

## Key Props

Use service category items with labels, copy, media, checklist items, and CTA targets.

## Style And Composition

The style preset should control tab states, focus states, media treatment, and panel spacing. It should remain keyboard accessible.
