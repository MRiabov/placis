# public.services.sector_tabs

## Purpose

Tabbed service-capability section for builders whose services need grouped
proof: buildings, civil infrastructure, industrial, maintenance, special
projects, and similar categories.

Use when services need an image, category narrative, and route link. For local
trades with simple task lists, prefer `public.services.cards` or
`public.services.grid`.

Source fit: PCL's "What we do" tabs.
