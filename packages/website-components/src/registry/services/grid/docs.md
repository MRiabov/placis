# public.services.grid

## Purpose

Use this component to show core services as short cards with optional links.

## Best Fit

Good for broad contractor home pages where visitors need to identify the relevant service quickly.

## Avoid

Avoid it when each service needs strong imagery and a large visual tile. Use `public.services.cards` for that shape.

## Key Props

Use `services[]` with service name, description, optional href, and optional price or CTA hints.

## Style And Composition

The style preset should control card surface, grid density, heading weight, and CTA treatment. Compose it after hero/context and before proof or contact sections.
