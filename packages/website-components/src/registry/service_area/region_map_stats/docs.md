# public.service_area.region_map_stats

## Purpose

Use this component for enterprise regional coverage sections that combine region
tabs, map imagery, and scale statistics.

## Best Fit

Good for large contractors, logistics businesses, multi-office operators, or
organizations whose geographic proof matters as much as the service-area list.

## Avoid

Avoid it for simple local service-area lists or contact-page map blocks. Use
`public.service_area.coverage` for those lighter cases.

## Key Props

Use title, body, region tabs, optional region-specific map images, and stat
items such as ownership, active project count, office count, or regional
workforce scale.

## Style And Composition

The style preset should own dark/light treatment, map opacity, tab underline
color, and large stat typography. Source-backed map URLs can be stored as
provenance while publication should resolve to owned durable assets.
