# public.content.leadership_grid

## Purpose

Use for image-led people rows where individual people need portraits, roles,
and short biographies.

## Best Fit

About website pages, founder pages, and partner rosters with sourced
headshots.

## Avoid

Do not use for anonymous reviews or logo/client grids.

## Key Props

Use `items[]` with `name`, `role`, `bio`, `image_url`, and `alt_text`.
Items are ordinary website slots; `{{leadership}}` is not a Common variable.
