# public.content.intro_metrics

## Purpose

Two-column positioning section with proof metrics. Use for contractors with credible scale facts:
years in business, project volume, crews, locations, certifications, or safety statistics.

Metrics must render as final static values in HTML. Animated counters can be progressive
enhancement later, but publication must not depend on JavaScript to turn `0` into meaningful proof.

Source fit: PCL's "Who We Are" narrative plus corporate proof counters.
