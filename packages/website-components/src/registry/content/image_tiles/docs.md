# public.content.image_tiles

## Purpose

Three-up image and copy tiles for broad destination links such as careers,
projects, and community impact.

## Props

Use `anchor_id`, `title`, and `items[]` with `title`, `description`,
`image_url`, `alt_text`, `href`, and `link_label`.

## Usage

Use when a section is primarily a routing surface and each destination benefits
from a strong image.
