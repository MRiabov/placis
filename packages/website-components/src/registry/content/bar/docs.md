# public.content.bar

## Purpose

Use this website component for compact metric rows near a hero, service
summary, or CTA.

The first fixture is decomposed from Bellfield's hero stats. Treat numbers,
ratings, guarantees, and certification marketing statements as content
backed by a detail. If they are imported from a site without verified
sources, keep `reviewRequired` true until a contractor or operator approves
them.

## Key Props

Use `items[]` for short metrics. Each item should have a compact label and
optional description; avoid long paragraphs or marketing statements that are
not backed by a detail.

## Style And Composition

The website component should inherit color, border, density, and typography
from the website style catalog preset. Place it directly after a hero, before
a CTA, or beside a service summary.
