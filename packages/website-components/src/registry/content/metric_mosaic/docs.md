# public.content.metric_mosaic

## Purpose

Large bordered grid for a small number of high-level business metrics,
certifications, and supporting images.

## Props

Use `anchor_id`, `title`, and `items[]` with `value`, `label`, `image_url`,
and `alt_text`.

## Usage

Use when the visual rhythm matters as much as the numbers. Avoid for small
bars or dense certification strips.
