# public.content.story_text

## Purpose

Use for editorial source pages that mix section headings, bold subheads, and
paragraph groups. It can render a centered article-style block or a split
image/text block.

## Best Fit

Company story sections, source-backed about-page body copy, anniversary notes,
and image-left editorial panels where the text hierarchy is part of the
reference.

## Avoid

Do not use for card grids, proof metrics, or short CTA copy.

## Key Props

Use `title`, optional `image_url`, `image_position`, and `blocks[]` with
`heading` and `paragraphs[]`. `paragraphs[]` can be used directly for simpler
body-only sections.
