# public.content.story_split

## Purpose

Use this component for editorial story content with media and longer narrative copy.

## Best Fit

Good for company stories, founder/operator sections, project case-study introductions, and credibility-building narrative.

## Avoid

Avoid it for short SEO blurbs or dense service lists. Use intro, split, or services components instead.

## Key Props

Use title, body copy, media, and optional attribution/profile metadata. Keep claims traceable when they mention credentials or project outcomes.

## Style And Composition

The style preset should control editorial rhythm, image treatment, and text measure. It pairs well with galleries, proof panels, or contact CTAs.
