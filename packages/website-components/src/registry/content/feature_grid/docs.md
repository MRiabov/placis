# public.content.feature_grid

## Purpose

Use this component for reusable feature, process, option, or benefit cards.

## Best Fit

Good when the page needs to compare multiple reasons, inclusions, service qualities, or decision factors.

## Avoid

Avoid it for primary service navigation if each card needs a service page CTA. Use service components for that.

## Key Props

Use `title`, optional intro copy, and `items[]` with title, body, icon, or media fields.

## Style And Composition

The style preset should control card border, surface, density, icon treatment, and grid spacing. Place it after context copy and before CTA/proof sections.
