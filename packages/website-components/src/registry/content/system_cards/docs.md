# public.content.system_cards

## Purpose

Editorial feature section with an index column and a set of image-backed scroll
states. Use it for methodology, operating systems, or service platforms where
the site needs to show a named framework rather than ordinary service cards.

Each item renders as its own state panel with the matching index item marked
active. Desktop themes can style those panels as discrete scroll stops, while
mobile themes can stack them as normal accessible content.
