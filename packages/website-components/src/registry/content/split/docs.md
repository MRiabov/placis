# public.content.split

## Purpose

Use this component for two-column explanatory content with supporting imagery.

## Best Fit

Good for about sections, service explanations, process summaries, and source-site blocks that combine copy with one strong image.

## Avoid

Avoid it when there is no useful image or when the copy is too long for a split layout.

## Key Props

Use `title`, optional `subheading`, `paragraphs`, `image_url`, `alt_text`, `image_position`, and optional `layout`.
`balanced` is the default for service/about copy, `compact` is for short blurbs, and `editorial` is for tall story-style media.

## Style And Composition

The component owns the split layout intent and heading/body rhythm. The style preset should govern image radius, typography, color, and divider treatment. Compose it between hero/CTA/services sections where the page needs context.
