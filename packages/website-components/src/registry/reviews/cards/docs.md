# public.reviews.cards

## Purpose

Use this website component to show short reviews with optional rating and
source markers.

## Best Fit

Good when individual quotes matter more than one featured review.

## Avoid

Avoid it for unsourced ratings, fabricated reviews, or dense carousel-only
layouts.

## Key Props

Use `items[]` with quote/body, name/author, optional rating, `source_label`,
and `source_url`.

## Style And Composition

The website style catalog preset should control card surface, star color,
source marker treatment, spacing, and readable contrast. Place it near FAQ,
gallery, or contact CTA website sections.
