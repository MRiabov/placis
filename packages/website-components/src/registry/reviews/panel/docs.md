# public.reviews.panel

## Purpose

Use this website component for a featured review or review cluster that needs
more visual weight than review cards.

## Best Fit

Good for contractor website pages where one strong review should carry more
weight.

## Avoid

Avoid it when all reviews should have equal weight or when review source
details are missing.

## Key Props

Use review quote, author, source, optional controls, and supporting labels.
Treat review marketing statements as content backed by a detail.

## Style And Composition

The website style catalog preset should control panel contrast, source label,
quote scale, and control styling. It pairs well with galleries or contact
panels.
