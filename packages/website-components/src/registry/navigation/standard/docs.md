# public.navigation.standard

## Purpose

Use this navigation variant for source sites with a contact strip, logo row, service links, and mobile menu behavior.

## Best Fit

Good for contractor sites where phone, email, or location proof needs to be visible before the main navigation.

## Avoid

Avoid it for minimal editorial sites where a single fixed header and CTA is enough.

## Key Props

Use `business_name`, `logo_url`, `phone`, `email`, `social_label`, `links`, and optional `service_links`.

## Style And Composition

The component renders SSR markup with progressive enhancement hooks for the mobile panel. Colors, spacing, logo sizing, and link states should come from the style preset.
