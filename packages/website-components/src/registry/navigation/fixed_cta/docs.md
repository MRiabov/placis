# public.navigation.fixed_cta

## Purpose

Use this navigation variant for public sites that need a persistent brand header, primary links, a mobile menu affordance, and one clear CTA.

## Best Fit

Good for polished contractor sites with a small set of top-level pages and one dominant action such as `Get a quote`, `Book a call`, or `Contact`.

## Avoid

Avoid it when the source site has a separate top contact strip or several contact methods that must remain visible. Use `public.navigation.standard` for that shape.

## Key Props

Use `business_name`, `logo_url`, `links`, and CTA link props. Navigation labels should be short and owner-readable.

## Style And Composition

The header should inherit typography, active state, focus ring, spacing, and CTA treatment from the selected style preset. It usually precedes one hero section.
