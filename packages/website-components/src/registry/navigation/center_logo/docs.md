# public.navigation.center_logo

## Purpose

Centered brand navigation for editorial or deep-navigation public websites where the logo is the
primary anchor and utility links sit on both sides.

## Props

Use `business_name`, `home_href`, `left_links`, `right_links`, `show_search`, and optional
`search_href`.

## Usage

Use when a page needs balanced top navigation, a compact search affordance, and a strong brand mark.
Avoid for small contractor sites where a phone-first CTA should dominate the header.
