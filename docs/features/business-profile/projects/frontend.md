# Projects Frontend Specification

A working Projects screen at `/cms/projects`: title, description, cover photo from the
media library. Not a stub.

Editing this screen updates the unpublished website / website editor immediately; the live
website changes only on the next website publication. Ads read the same live rows.

Left nav: [The CMS (sidebar + main area)](../../../general-architecture/cms/frontend.md). HTTP: [api.md](api.md).
Table: [persistence.md](persistence.md). Port: [frontend-debloat.md](frontend-debloat.md).
Headings have no decorative icon. On narrow, Open destinations stays inline with the heading.
