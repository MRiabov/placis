# Certifications

Trade accreditation ticks on the Certifications and reviews screen
(`/cms/certifications-and-reviews`). Rows live on
[business profile persistence](../details/persistence.md). HTTP:
[api.md](api.md). Go: `internal/profile/certifications/`.

The same Profile screen also has reviews: [reviews](../reviews/README.md). Screen: [reviews frontend](../reviews/frontend.md).
One-screen ADR: [reviews ADR](../reviews/ADR.md) 1. Look:
[reviews design decision record](../reviews/design-decision-record.md).
Optional `registry_url`: when set, the badge/card is a link (CMS and
the website). Null: not a link.
Withdrawn port: [frontend-debloat.md](frontend-debloat.md). Screen tests:
[reviews testing](../reviews/testing.md) (HTTP 1:1 stays Details
`testing.md`). Files: [business profile file trees](../file-trees.md).
